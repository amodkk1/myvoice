# MyVoice

Rewrites any article in your own writing style and removes plagiarism.

1. Add your Anthropic API key (stored only in your browser).
2. Write a few short samples on random topics so the app learns your style.
3. Paste an article; it is rewritten in your voice.
4. The result is checked against the original and the web, and flagged parts are fixed.

Live app: https://amodkk1.github.io/myvoice/
